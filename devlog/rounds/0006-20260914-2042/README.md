## 改动

### 一、标注工具（用户当面反馈）

**1. 批注框跑到屏幕外，点不到「添加」**

原来是按「面板高 300px」硬算位置的：
`top = min(rect.y + rect.height + 10, innerHeight - 300)`。
但面板高度是变化的 —— 选择器一长、批注一多就超过 300px，
于是底部连同「添加」按钮一起被顶到可视区外。

改成：先渲染、用 `ResizeObserver` 量实际尺寸，然后
**优先贴在元素下方 → 下方放不下就翻到上方 → 最后统一夹进视口**，
外加 `max-height: calc(100vh - 24px)` 与自身滚动兜底。

**2. 标注清单没有跟着「显示标注」一起显隐**

清单之前是独立判断的（`annotations.length > 0 && mode === 'browse'`），
现在统一成跟 `showPins` 走 —— 隐藏标注时清单也收起来。

**3. 连续标注要反复点模式按钮**

保存后代码里写死了 `setMode('browse')`，于是每标一笔都要重新点一次「点选 / 框选」。
改成保存后保持当前截获模式，可以一笔接一笔。

### 二、沉浸模式（标注 2/4）

标注 2 是个明显的体验坑：**进了沉浸模式就出不来** ——
右栏整块滑走时，连右上角的开关一起没了。

修法：舞台右上角补一个浮动的「退出沉浸」按钮（仅沉浸模式下出现）。
同时把侧栏开关的悬浮说明统一成「沉浸模式」。

### 三、右键菜单折叠更宽容（标注 1）

现象：父项和子菜单之间有一道视觉空隙，鼠标慢速划过去时会从空隙经过，
原来的「离开父项立刻收起」让子项根本点不到。

改成：**悬停即展开；离开后等 2 秒，且期间没有回到父项或进入子项，才收起**；
同时去掉子菜单的上下外边距，不留「空白陷阱」。

### 四、其它标注

取消卡片左上角的「横图/竖图」标记（3）；灯箱与帮助里的操作提示文案对齐
（5/6/7/8）；抓取面板显示真实规模（9/10）。

**关于 9/10**：新增了 `crawl:targetInfo`，切换抓取目标时查一次列表首页，
把「共 N 页 / M 条」写到「结束页」的说明和面板标题上，
不再写死「Pixiv萌图 目前约 1430 页」这种硬编码文案。

### 五、顺带修掉一个真实缺陷：导航解析把模板占位名当成了真实分类

做标注 9/10 的时候发现，页数**永远查不到**。追下去才看到：

站点 `<nav>` 里留了一段**注释掉的格式说明**，用的是
「一级分类名 / 二级分类名1 / 二级分类名2」这种模板占位名：

```html
<!--
<a class="nav_one"><p><span><img src="图标.png" /></span>一级分类名</p></a>
<section class="nav_two">
  <a href=".../plate/一级分类名/wd/二级分类名1.html"><p>二级分类名1</p></a>
```

而解析器当初**故意把注释也一起采集** —— 因为注释里还藏着真实分类
（搞笑图片，URL 至今可用）。结果这段模板也被当成真分类，
成了抓取目标里的**第一个**、也是**默认选中**的目标，指向一个不存在的分类，
页数自然查不到。

修法：把模板占位名单独识别并丢弃（不是简单跳过注释），
并在单测里补断言，防止以后又混进来。

这个缺陷还解释了一个之前没注意到的现象：抓取面板的分类列表里一直多一个
「一级分类名」分组，只是没人留意。

## 遗留

- 批注框的定位只考虑了「上下翻转」，没有做左右翻转的优先级策略 ——
  贴右边缘时是往左平移，多数情况够用，但极小窗口下仍可能压住目标元素
- 连续标注模式下没有「撤销上一笔」的快捷键，标错了要先去清单里删
- 抓取面板的总页数是**按首个选中目标**查的，多选时只反映第一个目标的规模
- 沉浸模式的状态存在模块级变量里，应用重启后回到默认（展开）
