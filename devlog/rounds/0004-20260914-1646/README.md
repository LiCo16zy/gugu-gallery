## 改动

### 一、标注工具（用户当面反馈）

1. **工具栏置顶**：记号是后渲染的兄弟节点，工具栏不给层级就会被覆盖。
   现在明确分层：记号 10 / 清单 25 / 气泡 29 / 工具栏 30 / 呼出把手 31 /
   编辑框 40 / 导出弹窗 60。
2. **5s 自动上收 + 鼠标靠近呼出**：收起后在顶部留一个 22px 的把手，
   显示当前模式与标注条数；鼠标进入顶部 88px 区域时把手显形，
   悬停 0.4s 或点击即可展开；截获模式下把手高亮，避免忘记还在点选状态。
3. **说明气泡改为点击选项后显示 5s**，不再常驻。

### 二、瀑布流（标注 19，本轮核心）

这是本轮最花心思的一处。

**做法**：CSS Grid + 4px 的隐式行，给每张卡**显式**计算 `grid-row` / `grid-column`。
这样既保住了正常文档流（懒加载、无障碍、`content-visibility` 都还能用），
又能让不同高度的卡片严丝合缝地错落堆叠 —— 每张卡的底部就是同列下一张卡的顶部。

横图（宽高比 ≥ 1.5）占两栏，因此每张卡还要在「可放置的相邻列组合」里挑当前最矮的那一组。

**踩到的两个坑**（都记在代码注释里了）：

- 列模板必须显式写成 `repeat(n, colWidth)`。留空会退回 CSS 里残留的 `auto-fill`，
  列数与计算值对不上，实测最后一列从 210px 缩到 145.67px。
- 容器宽度不能用 `useRef` 跟踪。首屏数据还没到时走的是空状态分支，
  网格元素根本不存在，观察器绑不上，宽度永远是 0。
  改成回调 ref + `ResizeObserver` 才正确。

新卡片逐张渐显 0.06s，各自独立播放。

### 三、侧栏

- 去掉分类的「全部收起」按钮；每个一级分类自带三角形折叠按钮，
  展开指向下、收起指向左，0.16s 转动，下方内容逐显渐隐
- 热门标签同样改成三角形开关
- 收藏图标改为爱心；「占用」改为「应用与存储」
- 隐藏滚动条（保留滚动能力），改为纵向 flex，帮助/设置沉到最底部
- **可拖动右边缘调宽**，上限为窗口宽度的 40%，栏内内容不随宽度缩放
- 展开/收起与拖宽都有 0.16s 过渡；收起时按钮图标真正居中
- 单个字母/数字不再作为标签展示

### 四、顶栏与窗口

- **关闭系统边框**，右上角自绘最小化/最大化/关闭；标题栏区域可拖动窗口。
  换掉 Windows 默认那条与整体风格不一致的标题栏
- 侧栏开关从顶栏移到品牌区：鼠标移上去「咕」渐变为侧栏图标
- 移除「图库/抓取/设置」三个按钮：设置与帮助沉到侧栏底部，
  帮助打开快捷键与关于弹窗
- 移除顶栏排序下拉，改为过滤栏里的折叠菜单
- 视图密度两个按钮合并为一个：标准=单个竖长方形、紧凑=两个，切换时 0.08s 交叉渐隐
- 品牌副标题改为「来自 gugu 小站的爱~」
- 品牌图标支持外部覆盖：放 `src/renderer/public/app-icon.png` 即可，取不到退回默认的「咕」字

### 五、卡片与过滤栏

- 副标题只留 pid 与浏览量；分辨率/体积/发布时间挪到悬停暗角
- 取消右上角收藏标记；收藏改为鼠标移入才出现的爱心按钮，
  点击变实心红色，移开卡片后按钮隐去但爱心保留
- 正文固定 50px 高 —— 瀑布流的计算依赖它是个常数
- **右键菜单**：收藏 / 复制 pid / 打开于…（折叠出文件管理器、Pixiv）；
  复制走主进程剪贴板，提示「已复制 pid」，停留 0.8s，淡入淡出各 80ms
- 过滤栏向下滚动收起（0.12s）、向上滚动展开（0.16s）
- 「待下载」与其它筛选项全部互斥；「已下载」只与「待下载」互斥

### 六、灯箱

- **修复竖图长边跑到屏幕外**：根因是 `.lightbox` 的网格行高是 `auto`，
  长图会把行撑高，于是 `max-height:100%` 永远满足不了。
  锁死 `grid-template-rows: minmax(0, 1fr)` 之后图片完整落在可视区内
- **交互按反馈重做**：左键随时可拖动平移，滚轮直接缩放（不再要求按住 Ctrl），
  取消原来的「点击放大 / 松手回退」逻辑
- 滚轮缩放以光标为锚点，指针下的像素保持不动
- 缩放下限放开到 25%，上限 600%，补了滑杆与禁用态
- **上传者逻辑**：站点把所有人都标成「匿名-分享」，没有信息量。
  改为优先显示详情页的 Pixiv 用户链接（它就是转载/上传者本人），
  并且不再额外宣称对方是「画师」——那只是上传者，未必是作者

### 七、其它

- 设置面板外观拆成两行：主题色 / 明暗；明暗补上「跟随系统」并实时监听
- 侧栏开合与视图密度切换时，内容页走一段
  「变暗到背景色 → 布局重排 → 亮回来」，总时长 0.16s，
  透明度低于 30% 的区间控制在 40ms 左右
- 轻提示抽出独立 Toast 组件，位置与动画固定

## 遗留

- **瀑布流还有优化空间**：跨栏卡片会在短列上留出空洞（实测最大 56px），
  更精细的做法是允许卡片「等待」更好的位置，但那会让 DOM 顺序与视觉顺序脱节
- 品牌图标的外部覆盖目前只支持固定文件名，没有做设置界面
- 「帮助」弹窗内容还比较薄，只有快捷键与版本信息
- 窗口最小尺寸下侧栏 40% 的上限会让内容区偏窄，暂未做响应式兜底
- 标注工具的多点命中测试是在固定视口下做的，极端窗口尺寸未覆盖
