## 改动

### 1. 搜索类目标抓回来的图带一个应用侧标签（标注 1）

站点的搜索页不会告诉你怎么找到这张图的，详情链接里带的还是图片原本的分类。所以 `kind === 'search'` 的目标在写入时额外补一个标签：

- `src/shared/categories.ts` 新增 `categoryTagFor(word)`：站点关键词（`泳装类分享`）→ 应用分类显示名（`泳装分享`），认不出来就原样返回；
- `engine.ts` 索引搜索目标时把 `[...raw.tags, categoryTagFor(target.word)]` 一起写进去。

标签是可点击的（侧栏「热门标签」与灯箱里的标签都会加筛选），所以「额外加标签」等于多了一条独立的筛选入口，和侧栏分类是两条路。**这条已经在真站点上验证过**（见下方验证一节）。

至于「此分类仅登录态可见」：上一轮已经做了，本轮没有改动 —— 侧栏分类和抓取目标两处都按登录态显隐。

### 2. 日期筛选挪到第二位、并且只精确到月（标注 2）

- 过滤栏顺序改为 `排序 → 日期 → 全部 → 收藏 → …`；
- 两个输入从 `type="date"` 换成 `type="month"`，取值 `YYYY-MM`；
- SQL 相应改成「下限补成当月 1 号 00:00、上限取下个月 1 号 00:00」，`nextDay()` 也随之换成 `nextMonth()`。`GalleryQuery.dateFrom/dateTo` 更名 `monthFrom/monthTo`。

只到月之后，「到 2026-09」天然包含整个 9 月，之前那段「上界要取次日 00:00 才不漏当天」的说明也就不需要了。

### 3. 帮助里的登录入口独立成引导弹窗（标注 3）

原来登录面板是塞在「帮助」里的，既不好找也不像一个独立动作。现在：

- 「帮助」底部左侧多一个 `登录` 按钮（`margin-right: auto`，右边仍是「访问网站 / 知道了」）；已登录时这个按钮置灰并显示 `已登录`；
- 点它会**先关掉帮助**，再弹出独立的 `LoginGuide` 弹窗（`data-component="App/LoginGuide"`）：贴 cookie、「保存并验证 / 重新验证 / 清除」、以及「去浏览器登录」；
- 验证通过后弹窗自动关闭并提示「登录态已生效」，回到帮助就能看到按钮变灰；
- 会话失效的提示文案也跟着改成「请到『帮助 → 登录』里重新贴一次 cookie」。

### 4. 顺手两件小事

- `cli.ts` 补上 `--search` 开关，无界面模式下也能抓关键词分类（`npx electron out/main/cli.js --search --word 泳装类分享 --pages 2 --index-only`），这样搜索类目标才有可自动化的自检入口；
- 新增 `tests/categories.test.ts`（7 项）：分类显隐、分类到目标的映射、标签映射。

## 遗留

- **登录态仍然没有真实验证过**：用户的会话 cookie 已失效，所以「登录后泳装分享分类出现在侧栏、计数正确」这条只能靠代码与单测保证。等用户换成新密码、重新贴一次 cookie 后再复核。
- 泳装分类的图现在来自站点对关键词「泳装类分享」的搜索结果。未登录时站点把它解析成「分享」（`<title>搜索：分享</title>`），返回的是分享区的图；登录后是否更精确，需要有效会话才能确认。
- 数据侧提醒：用户自己的 `data/demo` 里已经有一批 `泳装类分享` 的条目（100 条，抓取于本轮改动之前，因此没有 `泳装分享` 标签）。这些条目要等重新抓一次才会补上标签。
