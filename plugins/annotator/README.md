# annotator · 页面标注工具

在真实界面上点选元素 / 框选区域写批注，导出成可执行的修改说明。

- **怎么用**：看 [`SKILL.md`](SKILL.md)
- **依赖**：`devlog` 插件（`plugin.json` 里用 `dependsOn` 声明，构建期会校验）

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `renderer/index.tsx` | 插件入口：顶栏按钮 + 全屏覆盖层、事件拦截、批注编辑、导出 |
| `renderer/inspect.ts` | 元素自省：选择器、组件名、父级链、关键样式、对比度 |
| `renderer/annotator.css` | 工具样式（刻意的暖色调，与应用冷色主题区分） |
| `bin/check.mjs` | 自检程序，程序化驱动全流程 |

## 两个实现要点

**1. 用 document 捕获阶段的监听器拦截，而不是铺一层遮罩**

好处是能直接用 `e.target` 拿到真实元素（遮罩方案得反过来用 `elementFromPoint` 穿透自己），
而且工具栏、图钉、编辑框这些自己的 UI 不会被误拦截（靠 `closest('.gugu-anno-root')` 放行）。

**2. 位置同时记录视口坐标与文档坐标**

视口坐标用于截图裁切，文档坐标用于滚动后把标注钉在原地；
导出时再按当前滚动位置换算回视口坐标，保证裁切与标注框对齐。
