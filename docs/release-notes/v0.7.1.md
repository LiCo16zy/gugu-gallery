# 咕咕图库 v0.7.1 —— Tauri 2 重构版

针对 [咕咕小站](https://www.guguxz.com/)（ACG 图片分享站）的**桌面端爬虫 + 本地图库浏览器**。
抓取 → 索引 → 下载原图 → 生成缩略图 → 用界面翻看，全流程离线可用。

**Tauri 2（Rust）+ React 18 + TypeScript**：界面与 0.6.x 完全一致，外壳整体换成 Rust。

## 下载

- **安装包（Windows x64）**：`GuguGallery_0.7.1_x64-setup.exe`（约 2.8 MB）
  - NSIS 安装包，**按当前用户安装、不需要管理员**，可选安装位置、可创建桌面 / 开始菜单快捷方式；
  - 安装包**不含 WebView2 运行时**（Windows 10/11 自带；缺失时安装程序会引导在线装一个几 MB 的运行时）；
  - 应用**未做代码签名**，Windows SmartScreen 可能提示「未知发布者」，选择「更多信息 → 仍要运行」即可。
- 校验：安装包的 SHA-256 随 Release 一起提供（`SHA256SUMS.txt`）。

## 这一版有什么

### 外壳与体积

- Electron 33 → **Tauri 2**：主进程侧（窗口、抓取、存储、会话、系统集成、插件宿主）全部重写为 Rust；
- 渲染层与外壳的唯一耦合点是 `window.gugu`（29 个方法），所以**界面一行没改**；
- 安装包 **85 MB → 2.8 MB**、可执行文件 **180 MB → 7.4 MB**、`node_modules` **~700 MB → 92 MB**。

### 索引与数据

- `sql.js`（WASM，整库常驻内存 + 防抖导出）→ **rusqlite**（bundled SQLite，磁盘直写）；
- 表结构与 SQL 语义逐条对齐，`schema_version` 仍是 **3**：**老图库直接打开，不需要重建索引**。

### 抓取

- **详情补全**（Pixiv 作品号 / 画师主页 / 完整标签）在 Tauri 版补齐：下载前按需抓一次详情页，
  落盘文件名重新带上 `pid`（界面上的「下载前补全详情」开关真的生效了，嫌慢可以关掉）；
- **暂停 / 继续真实可用**：阶段显示「已暂停」、按钮切成「继续」、进度冻结；继续时从原队列接着跑，
  已下完的不会重来；单张「下载此图」同样可以被暂停；
- 运行日志**不再重复刷同一行**（进度事件只发送增量日志）；
- **文件缺失自愈**：本地文件被外部删掉时不再一直显示坏图，而是回到「这张图还没有下载到本地 + 下载此图」；
- 单张下载失败会在灯箱里给出**具体原因**（例如 `#19538 HTTP 403`），完整日志仍在「抓取任务」页。

### 界面

- 沉浸模式右下角**标题条**：左右切图后显示的是**新图**的信息（此前会串成上一张）；
- 「关于」面板去 Electron 化：应用版本 / 内核（Tauri + WebView2 版本）/ 平台 / 索引库（路径 · 大小 · schema）/ 数据来源；
- 设置里的**代理**说明与当前实现一致，且改完**立即生效**（抓取与登录校验都会走它）。

### 登录态

- 会话 cookie 存 **Windows 凭据管理器**（DPAPI 保护、绑定当前账户），仍然只存会话、不存账号密码；
- 校验失败会区分「网络不通」与「cookie 过期」，并在界面上明确提示；
- 有效登录后「泳装分享」出现，可索引、可下载（详情补全同样生效）。

### 命令行模式

`gugu-gallery.exe --…`（仓库里是 `npm run crawl -- …`）：`--plate/--word/--pages/--from/--max`、
`--index-only`、`--no-enrich`、`--search`、`--delay`、`--concurrency`、`--include/--exclude`、`--library`。
走的是和界面完全一样的引擎与落盘逻辑。

### 插件（开发工具，不进发布产物）

- 主进程侧插件改用 Rust 实现：轮次档案 `listRounds`、标注导出 `exportAnnotations`；
- 导出结构不变：`annotations.json` / `annotations.md` + 整页截图 + 每条标注的裁片 + 轮次 `README.md` 骨架。

## 兼容性

- **图库目录结构不变**，0.6.x 建的库可以直接用（schema v3）；
- 设置文件仍在 `%APPDATA%\gugu-gallery\settings.json`；
- 登录态因为换了存储位置，升级后需要**重新贴一次 cookie**；
- 与 0.6.x 可以共存安装（安装目录不同），卸载旧版不影响图库。

## 已知限制

- **登录态只覆盖「会话 cookie」这一条路**：站点需要过验证码，所以不做自动登录；cookie 过期后需要重新贴一次。
- **索引是本地 SQLite 文件**：单连接串行写入，抓取与界面查询共用它，十万条量级依旧流畅。
- **不做图片去重**：同一张图重复投稿会各自存一份。
- **抓取速率保守**：默认并发 2~3、间隔 220ms；站点本身约 1/4 请求会被截断，靠重试兜底，抓完整站需要一段时间。
- **只提供 Windows x64 构建**，且未做代码签名（Android 版本尚未开始）。
