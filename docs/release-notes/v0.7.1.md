# 咕咕图库 v0.7.0 —— 外壳换成 Tauri 2

同一套界面与交互，把外壳从 Electron 换成 **Tauri 2（Rust）**：
安装包 **85 MB → 2.8 MB**，可执行文件 **180 MB → 7.4 MB**。
抓取、索引、下载、浏览、登录态，功能一个不少。

## 下载

- **安装包（Windows x64）**：`GuguGallery_0.7.0_x64-setup.exe`（约 2.8 MB）
  - NSIS 安装包，**按当前用户安装、不需要管理员**，可选安装位置、可创建桌面/开始菜单快捷方式；
  - 安装包**不含 WebView2 运行时**（Windows 10/11 自带；缺失时安装程序会引导在线装一个几 MB 的运行时）；
  - 应用**未做代码签名**，Windows SmartScreen 可能提示「未知发布者」，选择「更多信息 → 仍要运行」即可。
- 校验：`GuguGallery_0.7.0_x64-setup.exe` 的 SHA-256 随 Release 一起提供（`SHA256SUMS.txt`）。

## 这一版改了什么

改动几乎全在**看不见的地方** —— 界面代码一行没动。

### 外壳

- Electron 33 → **Tauri 2**：主进程侧（窗口、抓取、存储、会话、系统集成）全部重写为 Rust；
- 渲染层与外壳之间只有 `window.gugu` 一份契约（29 个方法 / 33 处调用），所以换壳不用碰界面；
- 依赖从「Electron 全家桶 + sql.js」缩到「Tauri + React」：`node_modules` 由 ~700 MB 降到 **92 MB**。

### 索引

- `sql.js`（WASM，整库常驻内存 + 防抖导出）→ **rusqlite**（bundled SQLite，磁盘直写）；
- 表结构与 SQL 语义逐条对齐，`schema_version` 仍是 **3**：**老图库直接打开，不需要重建索引**。

### 登录态

- 会话 cookie 从 `session.bin`（DPAPI 加密文件）改为 **Windows 凭据管理器**；
- 仍然只保存会话 cookie，账号密码从不经过本应用；
- 因为存储位置变了，升级后需要**重新贴一次 cookie**。

### 截图与自检

- 原来的 `capturePage()` 换成 PrintWindow 抓窗口；harness 约定完全不变
  （`GUGU_SHOT` / `GUGU_EVAL` / `GUGU_DIAG` 与 `__EVAL__{…}` 输出格式照旧）；
- 63 项界面交互断言、37 项标注工具断言、16 项解析器单测全部照旧跑通。

### 命令行模式

- `npx electron out/main/cli.js --…` → **`gugu-gallery.exe --…`**（仓库里用 `npm run crawl -- …`）；
- 参数与输出格式与旧版一致；
- 新增 `imgdiff` 子命令（原来是依赖 Electron 的脚本）。

### 插件（开发工具，不进发布产物）

- 主进程侧插件（轮次档案 / 标注导出）改用 Rust 实现，**方法名、产物结构、目录布局全部不变**；
- 插件只在开发构建里启用；发布构建仍会**实际扫描产物**确认没有插件代码残留。

## 兼容性

- **图库目录结构不变**，v0.6.x 建的库可以直接用；
- 设置文件仍在 `%APPDATA%\gugu-gallery\settings.json`；
- 与 0.6.3 可以共存安装（安装目录不同），卸载旧版不影响图库；
- 首次启动若提示选择图库目录，选到原来的库根目录即可。

## 已知限制

- **登录态只覆盖「会话 cookie」这一条路**：站点需要过验证码，所以不做自动登录；cookie 过期后需要重新贴一次。
- **索引是本地 SQLite 文件**：单连接串行写入，抓取与界面查询共用它，十万条量级依旧流畅。
- **不做图片去重**：同一张图重复投稿会各自存一份。
- **抓取速率保守**：默认并发 2~3、间隔 220ms，抓完整站需要等待一段时间。
- **只提供 Windows x64 构建**，且未做代码签名（Android 版本尚未开始）。
