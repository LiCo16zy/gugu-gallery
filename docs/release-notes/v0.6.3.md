# 咕咕图库 v0.6.3 —— 首个发布版本

针对 [咕咕小站](https://www.guguxz.com/)（ACG 图片分享站）的**桌面端爬虫 + 本地图库浏览器**。
抓取 → 索引 → 下载原图 → 生成缩略图 → 用界面翻看，全流程离线可用。

Electron 33 + React 18 + TypeScript，索引使用 WebAssembly 版 SQLite（**零原生编译依赖**，`npm install` 之后直接能跑）。

## 下载

- **安装包（Windows x64）**：`GuguGallery-Setup-0.6.3.exe`（约 85 MB）
  - NSIS 安装包，可选安装位置、可创建桌面/开始菜单快捷方式；
  - 首次启动会引导选择图库目录（默认放在安装目录下的 `GuguGallery`）；
  - 应用**未做代码签名**，Windows SmartScreen 可能提示「未知发布者」，选择「更多信息 → 仍要运行」即可。

## 这一版有什么

### 抓取

- 两阶段流水线：先建立**索引**（只抓列表页，极省流量），再按条件下载原图；
- 下载的是**真·原图**（走站点 `dw=true` 通道），不是列表页的压缩预览图；
- 页码范围、条目上限、标签包含 / 排除、最小宽度与体积等过滤；**索引与下载都严格按设置的范围执行**；
- 站点约 25% 的请求会中断，内置**重试 + 完整性校验**；落盘先写 `.part` 再原子改名；
- 实时进度（页码 / 条目 / 下载数 / 速率）、运行日志、暂停 / 继续 / 取消；
- 无界面命令行模式：`npx electron out/main/cli.js --search --word 泳装类分享 --pages 3 --index-only`。

### 图库

- 左侧资料库导航（全部 / 收藏 / 已下载 / 待下载 / 分类 / 热门标签），支持侧栏拖宽与收起；
- 瀑布流网格，标准 / 紧凑两种密度；开启 IntersectionObserver 进场动画；
- 筛选：分类、标签（多选 AND/OR）、收藏、下载状态、横竖构图、最小宽度、**按发布月份区间**；
- 七种排序：最新发布 / 最早上传 / 浏览量 / 文件体积 / 标题 / 随机；
- 灯箱：滚轮缩放（以光标为锚点）、左键拖动、`←` `→` 翻页、`Esc` 关闭、沉浸模式、两步确认删除；
- 分类只有一层（Pixiv萌图 / 电脑壁纸 / 手机壁纸），界面不再出现「ACG图片」前缀。

### 登录态（可选）

- 站点有一部分内容（泳装分享）只在登录后可见。应用**不保存账号密码**：用浏览器登录后把会话 cookie 贴进来，用系统密钥链（DPAPI）加密保存；
- 会话失效会明确提示并只在有帮助的地方显示，过期文案与状态一目了然；
- 应用开着时每 30 分钟保活一次，并跟随站点的 `Set-Cookie` 轮换更新本地会话。

### 开发工具（发布构建不包含）

- **页面标注工具**：在运行中的应用里框选元素、写反馈、导出截图与结构化标注，用来驱动下一轮迭代；
- **开发过程档案**：每轮迭代生成 `devlog/rounds/<轮次>/`（截图、标注、代码 diff、说明），并用 `round/<轮次>` 标签固定。
- 两者都是可选插件：发布构建显式排除，并在产物里做残留特征检查。

## 已知限制

- 只提供 **Windows x64** 构建；未签名。
- 需要能访问目标站点；站点不稳定时依赖重试，速度会下降。
- 日期筛选只精确到月；`published_at` 为空的条目会被日期条件排除。
- 「泳装分享」的图来自站点对关键词的搜索结果，实际内容由站点决定。
